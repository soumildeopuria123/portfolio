# Soumil Deopuria — portfolio

Source for my personal portfolio site: AI/ML engineer, selected projects, certifications and a small canvas arcade.

**Live:** https://site-79d5c448471d4eae83bc4c5b9c7eb682.freebuff.page

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole page: nav, hero, about, skills, projects, certifications, connect and arcade sections. |
| `styles.css` | Design system, layout, light/dark themes and responsive rules. |
| `script.js` | Theme toggle, mobile menu, active-nav tracking, scroll reveals, learning-path rail, toolbox captions. |
| `games.js` | Three canvas games for the arcade section: retro race, snake and breakout. |
| `robots.txt` | Content-signal policy. |

## Projects section

Five project cards. Each live app card pairs an **Open the app** button with a link to its repo. The Recall card links to the live study app at https://site-da9af0de96b1451b933ba1842f96ed1a.freebuff.page/ — keep that link if the card is edited.

## Assets

The portrait, resume PDF and 21 certificate PDFs live in `assets/` and are served from the live site. They are binary files published separately from this repo, so a deployment made from this repo alone needs that `assets/` folder added.
